# 大和川 藤井観測所 水位アラート

大和川水系・大和川「藤井」観測所（大阪府藤井寺市）の水位が **0.9m 以上** になったら、
スマホに通知が届く仕組みです。GitHub Actions で無料・自動で動くので、
自分のPCやスマホを起動しっぱなしにする必要はありません。

## データの取得元について（重要）

「川の防災情報」トップサイト（river.go.jp/kawabou、地図で見るページ）は、
利用上の注意で「ツール等による定期的なデータ収集はお控えください」と
明記しています。そのため、このツールはそちらには一切アクセスしません。

代わりに、数値データの参照用に公開されている「水文水質データベース」
（www1.river.go.jp）のリアルタイム10分水位ページを、**30分に1回**だけ参照します。
観測値自体が10分〜1時間おきの更新なので、30分間隔でも実用上問題ありません。
（より高頻度・業務利用が必要な場合は、国交省が案内している
[河川情報数値データ配信事業](https://www.river.or.jp/koeki/opendata/index.html)
の利用をご検討ください。）

## 必要なもの

- GitHubアカウント（無料）
- スマホに [ntfy](https://ntfy.sh/) アプリを入れる（iOS/Android、アカウント登録不要）

## セットアップ手順

1. **ntfyのトピック名を決める**
   - ntfy.shは「トピック名」を知っている人なら誰でも購読・送信できる仕組みです。
   - 他人に推測されないよう、長めのランダムな文字列にしてください。
     例: 
   - スマホのntfyアプリでこのトピック名を「購読（Subscribe）」しておきます。

2. **GitHubに新しいリポジトリを作成**
   - Public / Private どちらでも構いません（Privateでも無料枠でActionsは使えます）。

3. **このフォルダの中身をすべてアップロード**
   - `check_water_level.py`
   - `requirements.txt`
   - `README.md`
   - `data/state.json`
   - `.github/workflows/check_water_level.yml`
   - フォルダ構造（`.github/workflows/...`、`data/...`）を保ったままアップロードしてください。

4. **Secretsにトピック名を登録**
   - リポジトリの `Settings` → `Secrets and variables` → `Actions` → `New repository secret`
   - Name: `NTFY_TOPIC`
   - Secret: 手順1で決めたトピック名

5. **Actionsに書き込み権限を付与**
   - `Settings` → `Actions` → `General` → `Workflow permissions` を
     **「Read and write permissions」** に変更して保存。
   - （state.json を自動コミットするために必要です）

6. **手動実行して動作確認**
   - `Actions` タブ → `Yamato river Fujii water level check` → `Run workflow`
   - 成功すると `data/state.json` が更新されます。
   - 水位が0.9m未満なら通知は届きません（ログで現在の水位を確認できます）。

7. **以降は自動実行**
   - `cron: "*/30 * * * *"` の設定により、以降は30分おきに自動でチェックされます。
   - 水位が0.9m以上になった時点で、ntfyアプリにプッシュ通知が届きます。
   - 一度通知したあとは、水位が0.9m未満に戻るまで再通知しません
     （0.9m付近で細かく上下しても通知が連発しないようにするためです）。

## しきい値や監視間隔を変える場合

- しきい値: `.github/workflows/check_water_level.yml` 内の `THRESHOLD_M: "0.9"` を変更してください。
- 監視間隔: 同ファイル内の `cron: "*/30 * * * *"` を変更してください
  （例: 1時間ごとなら `"0 * * * *"`）。あまり短くしすぎないようご配慮ください。

## 監視対象の観測所を変える場合

`check_water_level.py` 冒頭の `STATION_ID` を、対象観測所の
「観測所記号」（15桁の数字）に書き換えてください。
観測所記号は [水文水質データベース](http://www1.river.go.jp/) で
観測所名を検索すると確認できます。

## 注意点

- このデータは無人観測所からの速報値であり、機器の故障等による異常値が
  含まれる可能性があります。避難などの重要な判断には、気象庁・国交省の
  公式発表や自治体からの情報もあわせてご確認ください。
- GitHub Actionsのcronは「指定時刻ちょうど」ではなく数分程度前後することがあります。
- ntfy.shの無料枠を使っています。トピック名は公開しないようにしてください。
